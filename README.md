# Vallune Vinhos

Site institucional estático para o projeto empresarial fictício Vallune Vinhos. Não requer instalação nem processo de build.

## Visualizar

Abra `index.html` em um navegador. As imagens da Vallune ficam em `assets/`; as fontes tipográficas são carregadas de um serviço externo e precisam de conexão com a internet.

## Antes de publicar

- O catálogo, os kits, a identidade e o perfil social são os dados informados para a atividade.
- As estimativas de vendas e faturamento são fictícias e não representam lucro. As estimativas por rótulo somam 375 unidades/mês; a simulação matemática separada usa 330.
- Os preços unitários do catálogo diferem dos valores da simulação matemática e dos kits; as seções identificam essas bases separadamente.
- Revise dados e avisos antes de usar a página fora do contexto escolar.

O menu compacto para celular, as âncoras de navegação, a tabela expansível e o ano do rodapé funcionam sem bibliotecas JavaScript.
